# Graph Assets

`manifest.json` records the approved BrandBrain icon-set plan and the local
role-to-file contract. Asset generation is deferred because the BrandBrain
processor is not production-ready and the zero-cost mock run did not complete.

The UI intentionally falls back to deterministic glyphs while these files are
absent. Only validated, credential-free PNGs may be added here. Filenames must
be single safe lowercase PNG names; do not commit signed URLs or provider
credentials.
